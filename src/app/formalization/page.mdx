# Formalization Template (Lean 4)

This page provides the **standard recording format** for machine-checked proofs, Lean 4 lemmas, and formal mathematical statements.

---

## Template Structure

When documenting formalizations, use the following layout:

### 1. Statement & Motivation
- **Mathematical Statement**: Pen-and-paper formulation.
- **Target Invariant**: Specific property or bound being formalized.
- **Mathlib Imports**: Required module dependencies.

### 2. Formalization Code Template

```lean
import Mathlib.Data.Real.Basic
import Mathlib.Topology.MetricSpace.Basic
import Mathlib.Tactic

/-!
# Note Title: [Topic / Lemma Name]
Author: Dongwoo Lee
Status: [In Progress / Verified]
-/

namespace MathArchive.Template

/-- Definition of the target concept -/
def TargetConcept (X : Type*) [MetricSpace X] (s : Set X) : Prop :=
  IsOpen s ∧ IsCompact s

/-- Formal Statement: [Theorem Description] -/
theorem target_theorem {X : Type*} [MetricSpace X] (s : Set X)
    (h : TargetConcept X s) : s = ∅ ∨ (univ : Set X) = s := by
  -- Proof skeleton
  sorry

end MathArchive.Template
```

### 3. Proof Strategy & Invariants
- **Induction Basis**: Base case or hypothesis setup.
- **Key Tactics**: `simp`, `rw`, `apply`, `linarith`, `ring`.
- **Open Sorries / Edge Cases**: Unresolved goals or Mathlib dependency gaps.
