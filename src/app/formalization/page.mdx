# Formalization & Proof Verification

Interactive theorem proving enables mathematics to be rigorously checked by a computer kernel. This section documents experiments and projects using **Lean 4** and its mathematical library (**Mathlib**).

## Why Formalize?

- **Unambiguous Precision**: Every definition, hypothesis, and inference step is strictly typed.
- **Elimination of Gaps**: Subtleties that are easily overlooked in informal proofs must be fully verified.
- **Constructive & Dependent Type Theory**: Exploring the deep correspondence between computer programs and mathematical proofs (Curry-Howard isomorphism).

## Lean 4 Proof Structure

In Lean 4, mathematical propositions are types, and proofs are terms inhabiting those types.

```lean
import Mathlib.Data.Real.Basic
import Mathlib.Tactic

-- Example: Verifying the sum of first n natural numbers
theorem sum_first_n (n : ℕ) :
    2 * (List.range (n + 1)).sum = n * (n + 1) := by
  induction n with
  | zero => simp
  | succ n ih =>
    rw [List.sum_range_succ, mul_add, ih]
    ring
```
